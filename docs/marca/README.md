# Marca Manda Bué

Símbolo: um prato visto de cima (anel) com o monograma **MB** em traço contínuo e três linhas de
velocidade douradas à esquerda — comida entregue depressa. As cores (vermelho, preto/carvão e dourado)
lembram a bandeira de Angola sem a copiar.

| Ficheiro | Uso |
|---|---|
| `simbolo.svg` / `simbolo.png` | Símbolo da app do cliente (fundo vermelho) |
| `simbolo-operador.png` | Símbolo da app do operador (fundo carvão, anel vermelho) |
| `logotipo.svg` / `logotipo.png` | Logótipo horizontal, fundo transparente |
| `logotipo-fundo-claro.png` | Logótipo horizontal sobre branco |
| `simbolo-icone.svg` | Fonte do ícone das apps (1024 × 1024) |

Os ícones, o ícone adaptativo do Android (zona segura de 72 %) e o splash das apps estão em
`apps/*/assets/` e foram gerados a partir destes desenhos.

## Regras

- Vermelho cheio só para a acção principal de cada ecrã; nas listas, botões leves.
- O símbolo precisa de espaço livre à volta de pelo menos a altura das linhas douradas.
- Não esticar, rodar nem mudar as cores do símbolo; sobre fotos, usar o símbolo dentro do quadrado vermelho.
- Logótipo provisório: substituir quando houver a versão definitiva de um designer, mantendo os nomes dos ficheiros.
